# NEXUS IT

Moderní responzivní webová prezentace fiktivní IT společnosti NEXUS IT.

## Funkce

- Úvodní stránka s hero sekcí
- Přehled poskytovaných služeb
- Sekce O nás
- Reference klientů
- Kontaktní stránka
- Responzivní design pro mobilní zařízení
- Moderní tmavý vzhled s modrými prvky

## Použité technologie

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Inter)
